# Divya Gutti Academic Website

This website was created using Quarto in RStudio and published with GitHub Pages.

## How to rebuild the site

1. Open the Quarto project in RStudio.
2. Edit the `.qmd` files.
3. Run `quarto render`.
4. Quarto generates the website in the `docs/` folder.
5. Upload or push the updated files to GitHub.
6. GitHub Pages publishes the site from the `main` branch and `/docs` folder.
